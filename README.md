# SaaS Analytics Platform

## 🚀 Features
- User authentication (JWT)
- CSV upload
- Data analytics dashboard
- Per-user data isolation

## 🛠 Tech Stack
- FastAPI
- PostgreSQL
- Pandas
- Chart.js

## ☁️ Deployment
- Backend: Render
- Frontend: Vercel

## 🔐 Auth
JWT-based authentication

## 📊 Endpoints
- POST /login
- POST /upload
- GET /stats
- GET /me
